El Jacobiano, sin misterios

Construye el Jacobiano con derivadas parciales y resuelve sistemas no lineales mediante Newton–Raphson. Observa cada operación, no solo la respuesta.

1. Prepara el sistema

Escribe cada ecuación igualada a cero: por ejemplo, x^2 + y^2 - 4. Usa ^ para potencias y * para multiplicación.

Puedes escribir sin( ), cos( ), exp( ), sqrt( ), etc. Los ángulos se expresan en radianes.

2. Explora y resuelve

Selecciona un ejemplo o introduce tus ecuaciones y pulsa «Construir Jacobiano».

En cada paso resolvemos el sistema lineal J(xₖ) · Δx = −F(xₖ) y actualizamos xₖ₊₁ = xₖ + Δx. No hace falta calcular la matriz inversa.

3. Historial de iteraciones

Aquí aparecerá una fila por cada iteración. Haz clic en una fila para revisar sus cálculos.

¿Cómo usarlo en clase?

Primero: pide a tus alumnos que calculen una fila del Jacobiano a mano. Después: comparen con las derivadas simbólicas mostradas. Luego: evalúen el Jacobiano en el punto inicial, resuelvan el sistema lineal y comprueben la actualización. Finalmente: continúen las iteraciones y observen cómo disminuye el residuo.

Advertencia matemática: la convergencia depende del punto inicial. Si el Jacobiano es singular o casi singular, la iteración puede detenerse. Este simulador explica el Newton–Raphson clásico, sin amortiguación ni métodos alternativos.
